## IP-ADAPTER USAGE NOTES

- Pass reference_image_data (base64) in EditRequest to activate style/identity preservation
- attach_ip_adapter(pipe) is idempotent — safe to call every request
- ip_adapter_scale range: 0.4–0.7 = style retention + prompt following; 0.0 = disabled
- Works with: CosXL (instruction), SDXL inpaint, ControlNet pipelines
- Does NOT work with FLUX — use LoRA fine-tunes or textual inversion for FLUX style transfer

## VRAM REFERENCE

| Setup                          | VRAM  |
|-------------------------------|-------|
| SDXL base (existing)          | ~6 GB |
| + ControlNet-Union-SDXL       | ~9 GB |
| + IP-Adapter ViT-H            | ~11 GB|
| Full Phase 1 peak              | 14-16 GB |
| FLUX.1-schnell fp16           | ~24 GB| //This is probably way too haeavy
| FLUX.1-schnell nf4            | ~12 GB|
| FLUX + ControlNet-Depth nf4   | ~14 GB|

On 8 GB cards: use pipe.enable_sequential_cpu_offload() in every loader
